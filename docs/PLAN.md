# План сайту AI Radar

Повна версія з таблицями — на сторінці [`/plan/`](https://DEMO_URL/plan/) (українською та англійською).

## Мета
Скоротити шлях від «мені треба зробити лого / озвучку / апскейл» до 2–3 відповідних AI-сервісів і одразу показати, чи вони безкоштовні та чи потрібна реєстрація. Додатково: показувати нові AI-стартапи, яких ще немає у великих каталогах, і збирати органічний трафік через сторінки задач і ніш.

## Аудиторія
- **Креатори, SMM, дизайнери:** шукають інструмент під задачу, бажано безкоштовний і без реєстрації. Для них — пошук за задачею та фільтри ціни/доступу.
- **Фаундери та продакти:** хто ще працює в моїй ніші. Для них — ніші, новинки, порівняння, сортування за DR.
- **Маркетологи та SEO-фахівці:** нові гравці для партнерств і аутрічу. Для них — DR, дата появи, стек, TLD.
- **Інвестори та скаути:** ранні AI-стартапи, тренди AI-конструкторів. Для них — фільтр «AI-конструктор» (Lovable, v0, Bolt, Base44), сортування «спершу нові».

## Сторінки та структура
```
/                     головна: пошук, задачі, свіжі, топ за DR, ніші, «чесно про дані»
├── /tools/           21 задача
│   └── /tools/{задача}/   інструменти + фільтри ціни, доступу, API, open source, DR
├── /sites/           каталог: пошук і всі фільтри (стан у URL — можна поділитися)
├── /niche/{ніша}/    15 SEO-сторінок ніш AI-стартапів
├── /new/             новинки за останній тиждень даних
├── /site/{домен}/    картка: опис, факти, ціна/доступ із поясненням, схожі сайти
├── /compare/         порівняння до 3 сайтів (?d=a,b,c)
├── /plan/            план сайту
└── /en/…             англійська версія (українська — за замовчуванням)
```

## Ключові сценарії
1. Безкоштовний апскейлер без реєстрації: головна → «Покращення якості» → Ціна «Free / freemium» + Доступ «Без реєстрації» → картка → сайт.
2. Конкуренти AI-агента: Ніші → «AI-агенти» → «Спершу нові» → «Порівняти» на 3 картках.
3. Що нового зроблено на Lovable: Каталог → Конструктор «Lovable» → «Спершу нові».

## SEO
Статичні сторінки, згенеровані під час збірки, ЧПУ, унікальні title/description, canonical, hreflang uk/en/x-default, JSON-LD (WebSite + SearchAction, BreadcrumbList, ItemList, WebPage), sitemap.xml з альтернативами мов, robots.txt. Комбінації фільтрів отримують `noindex`, canonical веде на базову сторінку.
