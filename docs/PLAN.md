# План сайту AI Radar

> Внутрішній документ проєкту. На клієнтському сайті не публікується.

AI Radar — пошук AI-інструментів на основі публічного FreeSerp API (`index=sites`, головні сторінки).

- **Основа:** шукати не «AI взагалі», а інструмент під конкретну задачу й одразу бачити, чи він безкоштовний і чи потрібна реєстрація.
- **Фіча:** у кожній категорії видно найновіші AI-стартапи, що щойно з’явилися в індексі (блок «Нове в категорії», вкладки на головній, бейдж «Новий»).

## Мета
- Скоротити шлях від «мені потрібно зробити лого / озвучку / апскейл» до 2–3 відповідних сервісів.
- Показувати нові AI-продукти, яких ще немає у великих каталогах (FreeSerp щодня знаходить нові домени).
- Давати швидке порівняння за ціною, доступом, API, авторитетністю (DR) і стеком.
- Збирати органічний трафік: сторінки задач і ніш — посадкові сторінки під запити на кшталт «безкоштовний генератор лого» чи «AI для музики».

## Аудиторія

| Хто | Що шукає | Чим допомагає сайт |
|---|---|---|
| Креатори, SMM, дизайнери | Інструмент під задачу, бажано безкоштовний і без реєстрації | Пошук за задачею + фільтри ціни/доступу |
| Фаундери й продакти | Хто ще працює в моїй ніші, нові конкуренти | Ніші, «Новинки», порівняння, сортування за DR |
| Маркетологи та SEO-фахівці | Нові гравці для партнерств, лінкбілдингу, аутрічу | DR, дата появи, стек, фільтр TLD |
| Інвестори / скаути | Ранні AI-стартапи, тренди конструкторів (Lovable, v0, Bolt) | Фільтр «AI-конструктор», сортування «спершу нові» |

## Сторінки та структура
```
/                     головна: пошук (ніша + запит + підказки), задачі, «Нові стартапи за категоріями» (вкладки), ніші
├── /tools/           21 задача (музика, відео, лого, фавіконки, ретуш…)
│   └── /tools/{задача}/   «Нове в категорії» + інструменти з фільтрами: ніша, пошук, ціна, доступ, API, open source, DR
├── /sites/           «Усі AI-сайти»: усі фільтри (стан у URL — можна поділитися)
├── /niche/{ніша}/    15 SEO-сторінок ніш: «Нове в категорії» + список
├── /new/             «Нові стартапи»: останній тиждень наявних даних, ніша — перший фільтр
├── /site/{домен}/    картка: опис, факти, ціна/доступ із поясненням, схожі сайти
├── /compare/         порівняння до 3 сайтів (?d=a,b,c), додавання через ніша + пошук з підказками
└── /en/…             англійська версія всіх сторінок (українська — за замовчуванням)
```
- Кожна сторінка списку — один компонент із різними пресетами API-параметрів, тому фільтри поводяться однаково скрізь.
- Перший фільтр у кожній формі — **«Ніша»**. На сторінках задач він за замовчуванням дорівнює ніші задачі, на сторінках ніш — перемикає на іншу нішу.
- Усі поля пошуку мають підказки: задачі, ніші (локально, обома мовами) і сайти (з API, з урахуванням вибраної ніші).

## Ключові сценарії
1. **«Потрібен безкоштовний апскейлер без реєстрації»:** головна → плитка «Покращення якості» → Ціна «Free / freemium», Доступ «Без реєстрації» → картка → «Відкрити сайт».
2. **«Хто конкурує з моїм AI-агентом»:** Ніші → «AI-агенти» → «Спершу нові» → «Порівняти» на 3 картках → /compare/.
3. **«Що нового зробили на Lovable»:** Усі AI-сайти → Конструктор «Lovable» → «Спершу нові».
4. **«Порівняти Suno з конкурентами»:** Порівняння → Ніша «Аудіо й музика» → почати вводити назву → вибрати з підказок.
5. **«Що нового в генерації відео»:** головна → вкладка «Генерація відео» в «Нові стартапи за категоріями» → картка, або сторінка задачі → блок «Нове в категорії».

## Дані та API
- Джерело — `GET https://freeserp.ai/api.php`, index=sites (за замовчуванням). Використано: `ai_startups`, `ai_categories`, `ai` / `ai_source`, `tld`, `dr_min/max`, `from_date/to_date`, `sort/order`, `from/size`, `content` + `content_max`, `stats=1`, пошук домену через `q=домен&all=1`.
- **Ціни й доступу в API немає.** Їх визначає евристика за текстом головної сторінки (`content=1`, перші 4000 символів) і AI-описом: «free plan», «$9/mo», «free trial», «no sign up», «waitlist» тощо. Біля кожної позначки є пояснення з фразами, що спрацювали. Кнопка «Log in» не означає обов’язкової реєстрації, тому позначка називається «Є акаунти».
- Фільтр за ціною/доступом працює на клієнті: API так не фільтрує, тому беремо перші 100 результатів, класифікуємо й показуємо збіги (про це написано біля результатів).
- Задачі зіставлені з AI-нішами API; частина звужена текстовим запитом (апскейл, ретуш, лого). Для фавіконок окремої ніші немає — пошук за текстом.
- Обмеження й перевірки — у [`API_NOTES.md`](API_NOTES.md).

## SEO
Статичні сторінки, згенеровані під час збірки, ЧПУ, унікальні title/description, canonical, hreflang uk/en/x-default, JSON-LD (WebSite + SearchAction, BreadcrumbList, ItemList, WebPage), sitemap.xml з альтернативами мов, robots.txt. Комбінації фільтрів отримують `noindex`, canonical веде на базову сторінку.

## Технічне рішення
- HTML, CSS і ванільний JavaScript (ES-модулі), без фреймворків і залежностей.
- Під час збірки на Netlify Node-скрипт робить ~40 запитів до API й генерує статичні сторінки задач, ніш, новинок і карток сайтів обома мовами. Фільтри далі працюють у браузері через ті самі шаблони.
- Браузер звертається до API через проксі `/api/fs` (FreeSerp дублює CORS-заголовок).
- Кеш відповідей у sessionStorage, повтор при помилці, зрозумілі стани «порожньо / помилка».

## Що далі
- Щоденна перезбірка (Netlify build hook + cron), щоб статичні сторінки були свіжими.
- Щоденні знімки в БД, щоб показувати тренди ніш і конструкторів (API не має історії).
- Точніше визначення ціни: окремо завантажувати сторінку /pricing через `index=web`.
- Скріншоти сайтів, вибране, відгуки користувачів про точність позначок.
